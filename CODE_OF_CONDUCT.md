# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment,
personal attacks and discrimination are not tolerated in any project space.

Report unacceptable behavior privately to the maintainers through GitHub (a private security advisory works for
anything sensitive). Maintainers may remove comments, commits or contributions and ban participants who break these
rules.
